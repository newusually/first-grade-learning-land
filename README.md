# 🎒 一年级趣味学习乐园（First-Grade Learning Land）

一套专为 **小学一年级（6-7 岁）** 设计的纯前端互动学习网页，包含 **4 个页面**：口算动画课堂、看图学应用、数学测试卷、语文测试卷。全部**单文件 HTML、零依赖、离线可用**，双击即可运行，也可以一键部署到 GitHub Pages。

---

## ✨ 功能总览

| 页面 | 文件 | 主要功能 |
|---|---|---|
| 🏠 主页 | `index.html` | 四大乐园导航卡片、详细使用说明、动态背景、今日寄语（AJAX） |
| 🎬 口算动画课堂 | `口算动画课堂.html` | 加法 / 减法 / **凑十法**全程动画演示，数字范围 1–20（支持 10＋7），四种语言（中/英/日/西）界面＋语音朗读，WebAudio 音效，动态背景（太阳、白云、蝴蝶） |
| 📐 看图学应用 | `看图学应用.html` | 看图应用题闯关：两组相加、划走求剩、求总数、求部分、两步连加连减、序数排队题；表情图形逐个弹入动画＋语音读题；3 个难度＋混合闯关；每轮 10 题**随机出题** |
| 📝 数学测试卷 | `数学测试卷.html` | **随机组卷**（口算、比大小、看图列式、填空数序、解决问题、找规律、排队思考题），每轮 12 题；语音自动读题；自动评分、亮星星、撒彩带 |
| 📖 语文测试卷 | `语文测试卷.html` | 八大题型随机组合：看拼音写词、选读音、数笔画、量词、课文填空、**反义词连线**、阅读理解、**看图说话**；点击即判对错；全程语音 |

### 各页面共同特性

- 🎨 **CSS 动画**：卡片弹入、表情逐个出现、答对撒彩带、答对抖动提示、动态天空背景（太阳 / 云 / 气球 / 蝴蝶 / 星星 / 花草带）
- 🔊 **语音朗读**（Web Speech API）：自动读题、报答案、鼓励语；答对随机表扬
- 🔀 **随机出题**：每次进入或点「再来一轮」都会生成全新题目，内置防重复与超纲校验（一年级上册范围：10/20 以内加减，不出现退位减法等超纲内容）
- 🌐 **AJAX 扩展**：支持加载自定义题库（见下文），主页支持自定义今日寄语
- 🧭 **互相跳转**：主页 ⇄ 任意页面，任意页面 ⇄ 口算动画课堂，随时切换
- 📴 **完全离线**：无外部 JS/CSS/图片依赖，无网络也能用（语音使用系统自带 TTS）

## 🚀 快速开始

### 方式一：本地直接打开（最简单）

1. 下载本仓库（`Code → Download ZIP`，或 `git clone`）
2. 解压后**双击 `index.html`**（推荐 Edge / Chrome，语音效果最佳）
3. 点击任意卡片开始学习！

> 💡 提示：浏览器语音需要在页面上有过一次点击交互后才会发声，这是浏览器的安全策略。如果直接打开没声音，点一下页面上任意按钮即可。

### 方式二：GitHub Pages 在线访问

1. 仓库 `Settings → Pages`
2. Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
3. 保存后即可通过 `https://<你的用户名>.github.io/first-grade-learning-land/` 访问

## 🎮 各页面玩法说明

### 🎬 口算动画课堂

1. 顶部选择模式：**🍎 加法 / ✂️ 减法 / 🎁 凑十法**
2. 用 ＋/− 调整两个数（1–10，和/差自动防呆：减法保证够减、凑十法保证真进位，支持 `10＋7`）
3. 点「▶ 开始」观看动画：图形逐个飞入 → 大括号画出 → 逐个点数报数 → 答案揭晓＋彩带雨
4. 凑十法会演示「把 7 分成 2 和 5 → 8＋2＝10 → 10＋5＝15」的完整思考过程（金色 / 蓝色分色高亮）
5. 底部可切换语言（🌐）、语速、图形、🔊 语音和 🔔 音效开关

### 📐 看图学应用

1. 选难度：`① 10以内` / `② 20以内不进位` / `③ 进位退位挑战` / `🎲 混合闯关`
2. 每题：语音自动读题 → 看表情图动画（减法题会演示划走 ✕）→ 输入答案 → 点「✔ 检查」
3. 答对：+10 分、彩带雨、逐个点亮点数回放；答错：显示正确算式并朗读鼓励语
4. 序数题直接输入文字（如「第 3 个是橘子，前面有 2 个」或只填数字 3 也可）
5. 10 题一关，结算页亮星星，可换难度再战

### 📝 数学测试卷

- 每轮随机 12 题，覆盖八大题型，题号旁标注题型
- 普通题：输入数字后回车或点「✔ 检查」
- 比大小题：直接点 **＞ ＜ ＝** 大按钮
- 思考题包含**找规律**（如 1、3、5、7…）和**排队问题**（从前往后第 4、从后往前第 3，一共几人）
- 结束自动统计得分并朗读，点「🔄 再测一次」换新卷子

### 📖 语文测试卷

- 每轮随机 10 题，拼音、读音、笔画、量词、课文、阅读、看图说话全覆盖
- 全部点击作答，无需打字（适合刚上学的小朋友）
- **反义词连线**：先点左边的字，再点右边它的反义词，连错会抖动提示
- **看图说话**：看表情场景图大声说一段话，点「🎤 说好啦」即得分（鼓励式，不判对错）
- 课文填空均出自一年级上册必背：《一去二三里》《小小的船》《画》《静夜思》《咏鹅》

## 🌐 自定义题库（AJAX 高级用法）

三个练习页在启动时会尝试通过 AJAX 加载外部题库，**加载成功就用你的题，失败就用内置随机题库**：

| 页面 | 读取路径 | 格式 |
|---|---|---|
| 看图学应用 | `./题库/看图应用题.json` | 见 `题库示例/看图应用题.json` |
| 数学测试卷 | `./题库/数学测试卷.json` | 见 `题库示例/数学测试卷.json` |
| 语文测试卷 | `./题库/语文测试卷.json` | 见 `题库示例/语文测试卷.json` |

使用方法：把 `题库示例/` 里对应的 JSON 复制到网页同级的 `题库/` 文件夹（没有就新建一个），按示例格式改题目即可。

> ⚠️ 注意：浏览器安全策略下，`file://` 协议打开本地文件时 AJAX 可能被拦截（属正常现象，页面会自动回退到内置题库）；通过本地服务器或 GitHub Pages 访问时 AJAX 完全可用。

### 自定义主页寄语

在网页同级目录放一个 `banner.txt`，第一行会显示为主页的今日寄语。

## 🛠️ 技术栈

- **HTML5 + CSS3 + 原生 JavaScript（ES6）**，零框架、零依赖、零构建
- **Web Speech API**（`speechSynthesis`）：语音朗读，自动挑选中文音色
- **Web Audio API**：口算课堂的音效（弹入 / 划走 / 音阶 / 和弦），无需音频文件
- **Fetch API**（AJAX）：可选加载自定义题库 / 寄语，失败自动回退
- 全部页面响应式布局，平板、电脑均可使用

---

## 📌 教学范围说明

题目严格控制在**人教版一年级上册**进度内：

- ✅ 10 以内加减法、10–20 的认识、20 以内**不进位**加法与不退位减法
- ✅ 20 以内进位加法（凑十法）、序数与排队问题、简单两步运算
- ❌ 不包含退位减法（如 16−7，属下册内容）
