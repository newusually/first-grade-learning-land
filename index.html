使用说明

  1. 点击上面任意一张卡片即可进入对应练习页面；每个页面右上角都有 🏠 返回主页 按钮，可以随时回到这里。
  2. 口算动画课堂：先选模式（加法 / 减法 / 凑十法），调好两个数，点「开始」观看动画讲解，可切换中文 / English / 日本語 / Español，🔊 是语音讲解、🔔 是音效。
  3. 看图学应用：先选难度（10 以内 / 20 以内不进位 / 进位退位挑战 / 混合闯关），听语音读题 → 看图理解 → 填答案 → 点「检查」。
  4. 数学测试卷：随机 12 题，比大小题直接点 ＞ ＜ ＝ 按钮，其他题输入数字后回车或点「检查」。
  5. 语文测试卷：全部为点击选择题和连线题，看图说话题大声说出口后点「说好啦」即可得分。
  6. 所有页面都能离线使用：文件下载后双击用浏览器打开即可（推荐 Edge / Chrome，语音效果最佳）。
💡 进阶：想自定义题目？在网页同目录建一个 题库 文件夹，放入对应的 JSON 文件（看图应用题.json / 数学测试卷.json / 语文测试卷.json），页面会通过 AJAX 自动优先加载你的题库；没有就用内置题库。
